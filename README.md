# PVT-Simulator (Black Oil)

Простой PVT-симулятор Black Oil модели на классических корреляциях
(Standing, Vasquez-Beggs, Beggs-Robinson, Dranchuk-Abou-Kassem, Lee-Gonzalez-Eakin, McCain).

## Структура проекта

- `units.py` — конвертация единиц измерения (метрика Казахстан <-> field units США),
  включая МПа (частая единица давления в казахстанских PVT-отчётах)
- `pvt_correlations.py` — сами корреляции, всегда считают во внутренних field units
  (psi, °F, scf/stb) — это стандарт для этих корреляций
- `app.py` — Streamlit UI PVT-калькулятора, конвертирует ввод/вывод в выбранную
  систему единиц
- `field_data.py` — разбор "сырых" лабораторных PVT-таблиц по месторождению:
  многострочные шапки, гибкое сопоставление колонок по ключевым словам,
  очистка "грязных" значений, нормализация кодов горизонтов, регрессия
  для линий тренда
- `pages/1_Анализ_месторождения.py` — вторая страница приложения: загрузка
  таблицы отборов проб и построение зависимостей (Rs vs Pb, Bo vs Pb,
  вязкость vs Pb, свойство vs глубина и т.д.) по всему массиву или с
  группировкой по горизонту/блоку/скважине — работает и без колонки горизонта

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется браузер на `http://localhost:8501`.

## Проверка

- Тесты конвертации единиц: `python units.py` (должно вывести "все self-тесты пройдены успешно")
- В UI: слева выберите систему единиц ("Метрическая" или "Field units") — все поля
  ввода, таблица и подписи графиков должны пересчитаться и переименоваться
- Введите плотность нефти в кг/м³ — рядом появится справочное значение в °API
  (и наоборот при переключении в field units)
- На графиках отмечена вертикальная линия давления насыщения Pb
- Внизу страницы можно скачать таблицу в CSV или Excel и загрузить лабораторные
  PVT-данные для визуального сравнения с расчётными кривыми

## Диапазоны применимости корреляций

Каждая функция в `pvt_correlations.py` содержит в docstring диапазон
применимости в field units и его аналог в метрических единицах.
UI показывает предупреждения, если введённые параметры выходят за эти диапазоны.

## Анализ лабораторных данных по месторождению (страница «Анализ месторождения»)

Отдельная страница для загрузки "сырой" таблицы лабораторных отборов проб
(много скважин/горизонтов/блоков) и построения зависимостей между свойствами.

Как проверить:
1. `streamlit run app.py`, слева в навигации выбрать страницу
   «Анализ месторождения»
2. Загрузить xlsx/csv с таблицей отборов — программа сама предложит, с какой
   строки начинается шапка и данные (можно поправить), и предложит
   сопоставление колонок со стандартными полями (Горизонт, Pb, Rs, Bo,
   вязкость, глубина и т.д.) — тоже можно поправить руками
3. Строки-агрегаты вида «Среднее значение: горизонт …» определяются
   автоматически и по умолчанию исключаются из анализа
4. Коды горизонтов нормализуются (например, "PT-IV" и "РТ-IV", написанные
   разными алфавитами, будут считаться одним горизонтом)
5. В разделе «Зависимости» выбрать X/Y (например, Pb и Rs) и группировку
   (без группировки / по горизонту / по блоку / по скважине) — строится
   график рассеяния с линией тренда (линейной или степенной) и R² по каждой
   группе или по всему массиву целиком
6. Если в данных нет колонки горизонта/блока — соответствующие фильтры и
   группировки просто не показываются, всё остальное работает как обычно
